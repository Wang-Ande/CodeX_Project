# Sankey reference palette - organ flow colors

This folder contains one reference-inspired color effect for the latest Sankey layout. The data processing, axis alignment, labels, and flow alpha settings are unchanged from the final color-optimized version. The abundance colors follow the provided example figure: dark navy, mist blue, muted teal, wine red, and pale lavender. The left axis uses direct organ-level colors, and the flows from tissue-derived proteins to Global proteins are colored by their source organ rather than by the target neat abundance category.

## Inputs

- `Low_abundance_15ul_tidy.csv`: low-abundance/enriched protein table.
- `Plasma_Total_protein_tidy.csv`: neat/global protein table.
- `Specific tissue cluster2.xlsx`: tissue-specific organ annotation table.

## Shared data outputs

- `organ_to_neat_aligned_counts.csv`: organ-to-global category counts and aligned display weights used by all organ panels.
- `abundance_sankey_counts.csv`: global-to-enriched flow counts used by all abundance panels.
- `abundance_axis_totals.csv`: global and enriched axis totals.
- `alignment_check.csv`: confirms the organ panel Global protein axis matches the abundance panel Global protein axis.
- `palette_summary.csv`: compact list of the reference palette and its Q4/Q3/Q2/Q1/NA colors.
- `report.txt`: console log from this pipeline run.

## Palette folders

- `01_cell_fraction_reference_organ_flow_colors`: reference-style abundance palette with one color assigned directly to each requested organ; organ-to-Global flows use the same source-organ colors.

Each palette folder contains:

- `<palette>_organ_to_global.pdf`: tissue-derived proteins to Global proteins.
- `<palette>_global_to_enriched.pdf`: Global proteins to Enriched proteins.
- `palette_key.csv`: exact abundance and organ color hex codes.

## Plotting notes

- Q4/Q3/Q2/Q1 flows use alpha 0.74/0.72/0.68/0.64.
- NA flows use alpha 0.46 so the large undetected component remains visible on white backgrounds without dominating the Q flows.
- NA/Not detected is colored wine red (`#7A2E4D`) rather than grey; exact colors are listed in `palette_key.csv` and `palette_summary.csv`.
- In `<palette>_organ_to_global.pdf`, organ modules and organ-to-Global flows are colored directly by organ; Global modules are colored by abundance category.
- In `<palette>_global_to_enriched.pdf`, flows and modules are colored by abundance category.
- The plotted label `NA` corresponds to the original `Not detected` category.
